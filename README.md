# tty-atd

Простой сервер AT-команд для Linux. Программа читает команды из последовательного порта и отвечает по правилам из текстового словаря.

## Сборка

Требуются компилятор с поддержкой C++17 и CMake версии 3.16 или новее.

```sh
cmake -S . -B build
cmake --build build
```

Исполняемый файл будет создан по пути `build/atd`.

## Словарь команд

Каждая непустая строка содержит шаблон команды и ответ, разделенные первым символом `=`:

```text
AT=OK
ATI=tty-atd\r\nOK
AT+TEST*=MATCHED
AT+PORT.=OK
```

В шаблоне символ `*` соответствует любой последовательности символов, в том числе пустой. Символ `.` соответствует ровно одному любому символу. Экранирование этих символов в шаблоне не поддерживается. Правила проверяются по порядку, используется первое совпавшее.

Первый символ `=` в строке разделяет шаблон и ответ. Остальные символы `=` относятся к ответу. В ответах поддерживаются последовательности `\r`, `\n` и `\\`. Пустые шаблоны и ответы не допускаются, пустые строки игнорируются.

Пример словаря находится в `config/commands.txt`.

## Запуск

```sh
./build/atd --device /dev/ttyUSB0 --dictionary config/commands.txt
```

Скорость порта по умолчанию равна 115200 бод. Поддерживаются скорости 9600, 19200, 38400, 57600 и 115200 бод. При необходимости скорость можно указать явно:

```sh
./build/atd --device /dev/ttyUSB0 --dictionary config/commands.txt --baud 9600
```

Справка по аргументам:

```sh
./build/atd --help
```

## Поведение сервера

Сервер непрерывно читает поток данных из последовательного порта. Команда может прийти целиком или несколькими частями. В одном блоке данных также может находиться несколько команд.

Команда завершается символом `CR`, `LF` или парой `CRLF`. Пустые команды игнорируются. Обычные пробелы удаляются до поиска команды в словаре, поэтому `AT` и `A T` обрабатываются одинаково.

После получения полной команды сервер ищет первое подходящее правило в словаре. Ответ передается в формате:

```text
\r\n<ответ>\r\n
```

Если подходящего правила нет, сервер возвращает:

```text
\r\nERROR\r\n
```

Максимальная длина команды после удаления пробелов составляет 1024 байта. Если команда длиннее, сервер отбрасывает ее остаток, после завершителя возвращает `ERROR` и продолжает принимать следующие команды.

При ошибке чтения или записи, закрытии порта либо ошибке в словаре программа выводит сообщение в стандартный поток ошибок и завершается с кодом `1`.
